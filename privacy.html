RDB VPN Privacy Policy

Используя RDB VPN, вы соглашаетесь с данной политикой конфиденциальности.

Какие данные собираются

  • Telegram ID
  • Telegram Username
  • VPN-конфигурация
  • Данные подписки

Для чего используются данные

  • Предоставление VPN-доступа
  • Генерация конфигураций
  • Поддержка пользователей

Что мы НЕ храним

  • Историю посещений
  • Содержимое трафика
  • DNS-запросы

Передача данных

Данные не передаются третьим лицам, кроме случаев, необходимых для работы Telegram API и обработки платежей.

Удаление данных

Пользователь может запросить удаление данных через поддержку.
